# URBAN 10

Sitio web oficial del proyecto residencial boutique URBAN 10, ubicado en Barrio La Granja, San Pedro de Montes de Oca, Costa Rica.

## Desarrollo local

```bash
npm install
npm run dev -- --host 127.0.0.1
```

La aplicación utiliza React, Vite, TypeScript y Tailwind CSS.

## Comandos

- `npm run dev`: inicia el servidor local.
- `npm run build`: compila la versión de producción.
- `npm run lint`: ejecuta las validaciones de código.
